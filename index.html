La app detecta automáticamente las columnas del fichero Tropela. Busca columnas con estos nombres (sin importar mayúsculas/tildes):

  • Etapa / Stage / Etapa nº — número de etapa
  • Ciclista / Corredor / Nombre / Name / Rider — nombre del ciclista
  • Posición / Pos / Position / Llegada — posición de llegada
  • Puntos / Pts / Points / Score — puntos Tropela (opcional, si no está se calculan internamente)

Si el XLSX tiene varias hojas, la app usará la primera hoja con datos. Si hay resultados de varias etapas en el mismo fichero, las importa todas a la vez.

Guía de configuración para nueva competición
Sigue estos 4 pasos para adaptar la app a cualquier carrera
PASO 1 — DATOS DE LA COMPETICIÓN
Abre el fichero index.html con un editor de texto (Notepad, TextEdit, VS Code…) y localiza el bloque ZONA DE CONFIGURACIÓN cerca del inicio del código JavaScript.
Cambia los valores de CONFIG:
  • nombre — nombre completo: "Vuelta a España 2026"
  • nombreCorto — versión corta: "La Vuelta 2026"
  • emoji — icono representativo: 🚴 🏔️ 🌹 🌸
  • fechas — rango de fechas: "15 ago – 6 sep"
  • storageKey — clave única (diferente a otras competiciones para no mezclar datos): "fantasy_vuelta2026"
PASO 2 — JUGADORES
En JUGADORES_CONFIG pon un objeto por cada participante.
Puedes tener de 2 a 16 jugadores. El color es opcional — si lo dejas vacío ("") se asigna automáticamente de la paleta.
const JUGADORES_CONFIG = [
  { nombre: "MARTA",  color: "#e8005a" },
  { nombre: "LAURA",  color: "" },       // ← color automático
  { nombre: "SOFÍA",  color: "#22d47a" },
  { nombre: "ELENA",  color: "" },
];
PASO 3 — ETAPAS
Rellena el array ETAPAS con las etapas reales de la competición.
Los tipos disponibles son: Llano · Media Montaña · Alta Montaña · Contrarreloj · Descanso
Para los descansos usa n:"D" (las "D" no puntúan ni aparecen en clasificaciones).
{n:1, fecha:"15 ago", desc:"Lisboa → Madrid",  tipo:"Llano",        km:180},
{n:2, fecha:"16 ago", desc:"Madrid → Segovia",  tipo:"Media Montaña", km:165},
{n:"D",fecha:"17 ago", desc:"Descanso",         tipo:"Descanso",      km:0},
PASO 4 — CICLISTAS Y ELECCIONES
Rellena CICLISTAS_BASE con todos los ciclistas del pelotón.
En jugadores:[] pon los nombres exactos de quienes han elegido ese ciclista (pueden elegirlo 0, 1 o varios jugadores).
Las categorías disponibles son: Máximos favoritos · Favoritos · Escaladores · Sprinters · Cazadores y especialistas · Gregarios · A por el verde
{nombre:"Pogačar, Tadej",  equipo:"UEX", cat:"Máximos favoritos", jugadores:["GOLLUS","EUGENIO"]},
{nombre:"Del Toro, Isaac", equipo:"UEX", cat:"Escaladores",       jugadores:["NACHO"]},
{nombre:"Kooij, Olav",     equipo:"DCT", cat:"A por el verde",    jugadores:[]},
💡 Truco: puedes preparar el listado de ciclistas en Excel y copiarlo como texto. El formato Apellido, Nombre es el estándar (coincide con el XLSX de Tropela).
✅ Una vez configurado, guarda el fichero y ábrelo en el navegador. Los datos se guardan automáticamente en el navegador con la clave que hayas definido en storageKey, así puedes tener varias competiciones abiertas en paralelo sin que interfieran.

Esta app permite gestionar una liga de Fantasy Ciclismo. Cada jugador elige un equipo de ciclistas y acumula puntos según el rendimiento de estos en cada etapa.

Los 6 jugadores de esta liga son CARLOS, EUGENIO, GOLLUS, HÉCTOR, JAIME y NACHO. Cada uno eligió ciclistas de diferentes categorías (Máximos favoritos, Escaladores, Sprinters, Cazadores y especialistas, Gregarios, A por el verde...). Los ciclistas y sus elecciones se cargan desde el Excel.

Los puntos se leen directamente del fichero XLSX de Tropela que subas. La app usa los puntos exactos que Tropela asigna a cada ciclista — no los calcula internamente.

Si los datos cargados no incluyen puntos Tropela (por ejemplo, los datos de ejemplo o ficheros JSON/CSV sin columna de puntos), la app aplica una tabla de referencia estándar como fallback: 1º→155, 2º→95, 3º→75, 4º→60, 5º→50…

Opción 1 — XLSX de Tropela (recomendada): Ve a la sección Resultados y pulsa "Subir XLSX de Tropela". La app leerá las columnas automáticamente y mostrará una vista previa antes de importar. Compatible con ficheros de una o varias etapas.

Opción 2 — JSON / CSV: Arrastra o sube un fichero JSON o CSV con la estructura estándar (campos etapa, ciclista, posicion). Si la etapa ya tiene datos, la app te avisará y podrás sobrescribirlos.

Los datos se guardan en localStorage y persisten entre recargas.

Las etapas 1–4 ya tienen resultados cargados para que puedas ver la app en funcionamiento. Puedes resetear estos datos desde la sección Resultados → botón "Resetear datos".
